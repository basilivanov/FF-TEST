qwen [options]

Qwen Code - Launch an interactive CLI, use -p/--prompt for non-interactive mode

Опции:
  -m, --model                                 Model  [строковой тип]
  -p, --prompt                                Prompt. Appended to input on stdin (if any).  [строковой тип]
  -i, --prompt-interactive                    Execute the provided prompt and continue in interactive mode  [строковой тип]
  -s, --sandbox                               Run in sandbox?  [булевый тип]
      --sandbox-image                         Sandbox image URI.  [строковой тип]
  -d, --debug                                 Run in debug mode?  [булевый тип] [по умолчанию: false]
  -a, --all-files                             Include ALL files in context?  [булевый тип] [по умолчанию: false]
      --all_files                             Include ALL files in context?  [устар.: Use --all-files instead. We will be removing --all_files in the coming weeks.] [булевый тип] [по умолчанию: false]
      --show-memory-usage                     Show memory usage in status bar  [булевый тип] [по умолчанию: false]
      --show_memory_usage                     Show memory usage in status bar  [устар.: Use --show-memory-usage instead. We will be removing --show_memory_usage in the coming weeks.] [булевый тип] [по умолчанию: false]
  -y, --yolo                                  Automatically accept all actions (aka YOLO mode, see https://www.youtube.com/watch?v=xvFZjo5PgG0 for more details)?  [булевый тип] [по умолчанию: false]
      --telemetry                             Enable telemetry? This flag specifically controls if telemetry is sent. Other --telemetry-* flags set specific values but do not enable telemetry on their own.  [булевый тип]
      --telemetry-target                      Set the telemetry target (local or gcp). Overrides settings files.  [строковой тип] [возможности: "local", "gcp"]
      --telemetry-otlp-endpoint               Set the OTLP endpoint for telemetry. Overrides environment variables and settings files.  [строковой тип]
      --telemetry-log-prompts                 Enable or disable logging of user prompts for telemetry. Overrides settings files.  [булевый тип]
      --telemetry-outfile                     Redirect all telemetry output to the specified file.  [строковой тип]
  -c, --checkpointing                         Enables checkpointing of file edits  [булевый тип] [по умолчанию: false]
      --experimental-acp                      Starts the agent in ACP mode  [булевый тип]
      --allowed-mcp-server-names              Allowed MCP server names  [массив]
  -e, --extensions                            A list of extensions to use. If not provided, all extensions are used.  [массив]
  -l, --list-extensions                       List all available extensions and exit.  [булевый тип]
      --ide-mode-feature                      Run in IDE mode?  [булевый тип]
      --openai-logging                        Enable logging of OpenAI API calls for debugging and analysis  [булевый тип]
      --openai-api-key                        OpenAI API key to use for authentication  [строковой тип]
      --openai-base-url                       OpenAI base URL (for custom endpoints)  [строковой тип]
      --tavily-api-key                        Tavily API key for web search functionality  [строковой тип]
      --proxy                                 Proxy for gemini client, like schema://user:password@host:port  [строковой тип]
      --include-directories                   Additional directories to include in the workspace (comma-separated or multiple --include-directories)  [массив]
      --load-memory-from-include-directories  If true, when refreshing memory, QWEN.md files should be loaded from all directories that are added. If false, QWEN.md files should only be loaded from the primary working directory.  [булевый тип] [по умолчанию: false]
  -v, --version                               Показать номер версии  [булевый тип]
  -h, --help                                  Показать помощь  [булевый тип]
