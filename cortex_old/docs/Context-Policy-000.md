# Политика контекста

## Слои контекста

| Слой            | Что содержит                    | Кто читает           | Лимит токенов |
| --------------- | ------------------------------- | -------------------- | ------------- |
| Capsule         | краткий свод проекта            | все                  | 1–2k          |
| Role Charter    | устав текущей роли              | все                  | 800           |
| Task Packet     | intent/contract/plan для задачи | соответствующая роль | 2–3k          |
| Scoped Doc Pack | выборка по селекторам           | роль по запросу      | 2–3k          |

* **Dev/QA/Scribe получают только Task Packet + Scoped Doc Pack (selector-ы).**
* **Architect/Maintainer могут запрашивать расширенный контекст.**

## Секреты

* Секреты редактируются/заглушаются до передачи в контекст.

## Таймауты/ограничения

* Ограничение на количество документов в Scoped Pack: ≤ 8; суммарно ≤ 3k токенов.
