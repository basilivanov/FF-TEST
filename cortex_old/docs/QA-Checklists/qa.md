# QA-Checklist: QA

## Общие проверки

* [ ] Проверяем: валидность `qa_report.md` или `qa_report.json`, наличие всех обязательных проверок.
* [ ] Запрещено: "PASS" без фактических проверок по схемам, отсутствие логов/протоколов.
* [ ] Мини-набор тестов: валидация структуры отчета, проверка метрик покрытия.
* [ ] PASS: все проверки зелёные; FAIL: хотя бы один критический пункт.

## Таблица типовых ошибок

| Ошибка | Описание | Критичность |
|--------|----------|-------------|
| Нет отчета | Отсутствует `qa_report.md` или `qa_report.json` | Высокая |
| Невалидный отчет | Отчет не проходит схему валидации | Высокая |
| Нет проверок | Отчет содержит "PASS" без фактических проверок | Высокая |
| Нет логов | Отсутствуют журналы/протоколы тестов | Высокая |
| Нет метрик | Нет метрик покрытия критических веток | Средняя |
| Двусмысленный результат | Результат проверки неоднозначен | Высокая |
