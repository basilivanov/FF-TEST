## Выполненные работы

### 1. Создание и обновление API-документации

#### 1.1. docs/API-Orchestrator-001.md
Создана полная спецификация API оркестратора с детальным описанием всех четырех эндпоинтов:

**Эндпоинты:**
1. `POST /api/v1/orchestrator/features` - Создание новой фичи
   - Вход (JSON): `{"title": str, "intent": object|str, "priority": int}`
   - Выход 200 (JSON): `{"feature_id": int, "status": "NEW"}`

2. `POST /api/v1/orchestrator/features/{id}/plan` - Порождение DAG (Architect) и tasks
   - Выход 200: `{"feature_id": int, "tasks": [{"id": int, "role": str, "status":"NEW"}]}`
   - Выход 404: `{"error": "FEATURE_NOT_FOUND"}`

3. `POST /api/v1/orchestrator/features/{id}/run` - Запуск/резюмирование G1
   - Выход 200: `{"run_id": str, "status": "RUNNING|DONE"}`

4. `GET /api/v1/orchestrator/graph/{run_id}/status` - Получение статуса графа
   - Выход 200: `{"run_id": str, "graph":"G1", "nodes": [{"name": str, "state": "NEW|RUNNING|DONE|FAILED"}]}`

**Структура документа:**
- Обзор
- Эндпоинты (4 шт.)
- JSON Schema (4 шт. как код-блоки)
- Идемпотентность
- Коды ошибок
- Журналы событий
