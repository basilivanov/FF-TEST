# Метрики ролей в UI

## Общие положения

Этот документ описывает метрики по ролям, которые отображаются в Admin UI, и частоту их обновления.

## Метрики (per-role/24h)

### 1. calls
- **Описание**: Количество вызовов LLM для каждой роли за последние 24 часа
- **Источник**: События `llm_call_end` в логах
- **Тип**: Счетчик
- **Единицы измерения**: Вызовы

### 2. avg_latency_ms
- **Описание**: Среднее время latency вызовов LLM для каждой роли за последние 24 часа
- **Источник**: Поле `latency_ms` в событиях `llm_call_end`
- **Тип**: Среднее значение
- **Единицы измерения**: Миллисекунды

### 3. p95_latency_ms
- **Описание**: 95-й процентиль времени latency вызовов LLM для каждой роли за последние 24 часа
- **Источник**: Поле `latency_ms` в событиях `llm_call_end`
- **Тип**: Процентиль
- **Единицы измерения**: Миллисекунды

### 4. fallback_rate
- **Описание**: Процент вызовов, которые использовали fallback провайдера, для каждой роли за последние 24 часа
- **Источник**: События `llm_fallback` в логах
- **Тип**: Процент
- **Единицы измерения**: Процент от общего количества вызовов

### 5. budget_used/limit
- **Описание**: Использованный бюджет токенов по отношению к лимиту для каждой роли за последние 24 часа
- **Источник**: События `llm_call_end` и `llm_budget_exceeded` в логах
- **Тип**: Соотношение
- **Единицы измерения**: Токены использовано / Токены лимит

### 6. gate_rejects
- **Описание**: Количество отклонений Gate для каждой роли за последние 24 часа
- **Источник**: События `artifact_rejected` в логах
- **Тип**: Счетчик
- **Единицы измерения**: Отклонения

## Сводка на дашборде

### Общие метрики по всем ролям
- **Общее количество вызовов LLM**: Сумма всех вызовов по всем ролям
- **Средний latency**: Среднее значение latency по всем ролям
- **Общий fallback rate**: Процент fallback вызовов по всем ролям
- **Общий budget usage**: Общее количество использованных токенов по всем ролям
- **Общее количество Gate rejects**: Сумма всех отклонений Gate по всем ролям

### Графики и диаграммы
1. **График вызовов по ролям**: Линейный график с количеством вызовов для каждой роли за последние 24 часа
2. **Диаграмма latency**: Столбчатая диаграмма со средним и 95-м процентилем latency для каждой роли
3. **Диаграмма fallback rate**: Круговая диаграмма с процентом fallback вызовов для каждой роли
4. **График использования бюджета**: Линейный график с использованием бюджета по ролям
5. **Диаграмма Gate rejects**: Столбчатая диаграмма с количеством отклонений Gate для каждой роли

## Детализация по роли

### Страница детализации для каждой роли
1. **История вызовов**: Таблица с последними 100 вызовами LLM для роли
2. **Детали по ошибкам**: Таблица с последними ошибками и fallback вызовами
3. **Использование бюджета**: График использования бюджета по часам
4. **Тренды**: Графики трендов по основным метрикам за последние 7 дней

## Частота обновления

### Сводка на дашборде
- **Частота обновления**: Каждые 10-15 секунд
- **Источник данных**: Агрегированные данные из логов за последние 24 часа
- **Метод обновления**: Автоматическое обновление через Server-Sent Events (SSE)

### Детализация по роли
- **Частота обновления**: Каждые 5 секунд при активном просмотре страницы роли
- **Источник данных**: Агрегированные данные из логов за последние 24 часа
- **Метод обновления**: Автоматическое обновление через Server-Sent Events (SSE)
