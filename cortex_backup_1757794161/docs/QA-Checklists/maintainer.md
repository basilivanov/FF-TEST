# QA-Checklist: Maintainer

## Общие проверки

* [ ] Проверяем: валидность `intent.json`, наличие всех обязательных полей.
* [ ] Запрещено: отсутствие обязательных полей, неприменимые цели.
* [ ] Мини-набор тестов: валидация структуры intent, проверка класса и scope.
* [ ] PASS: все проверки зелёные; FAIL: хотя бы один критический пункт.

## Таблица типовых ошибок

| Ошибка | Описание | Критичность |
|--------|----------|-------------|
| Нет intent | Отсутствует `intent.json` | Высокая |
| Невалидный intent | `intent.json` не проходит схему валидации | Высокая |
| Нет обязательных полей | Отсутствуют обязательные поля в intent | Высокая |
| Неприменимая цель | Цель вне домена/политик безопасности | Высокая |
| Нет уточнений | При необходимости не запрошены уточнения (NEED_MORE_CONTEXT) | Средняя |
| Нет логов | Отсутствуют логи intake (start/end) | Средняя |
