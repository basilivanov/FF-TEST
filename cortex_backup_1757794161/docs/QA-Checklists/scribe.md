# QA-Checklist: Scribe

## Общие проверки

* [ ] Проверяем: валидность обновленных документов, CHANGELOG и doc_registry.
* [ ] Запрещено: битые ссылки, повторяющиеся заголовки, отсутствие события `doc_updated`.
* [ ] Мини-набор тестов: проверка структуры документов, валидность ссылок.
* [ ] PASS: все проверки зелёные; FAIL: хотя бы один критический пункт.

## Таблица типовых ошибок

| Ошибка | Описание | Критичность |
|--------|----------|-------------|
| Битые ссылки | Наличие неработающих ссылок в документации | Высокая |
| Повторяющиеся заголовки | Наличие дублирующихся H1/H2 заголовков | Высокая |
| Нет события doc_updated | Отсутствует событие `doc_updated` в логах | Высокая |
| Невалидная структура | Неправильная структура документов (отсутствие обязательных разделов) | Средняя |
| Нет обновления CHANGELOG | CHANGELOG не обновлен с датой | Средняя |
| Нет записи в реестре | Нет записи в `doc_registry` | Высокая |
