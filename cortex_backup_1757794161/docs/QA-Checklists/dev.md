# QA-Checklist: Dev

## Общие проверки

* [ ] Проверяем: валидность `artifact_manifest`, пути, отсутствие секретов, лог `llm_call_end`.
* [ ] Запрещено: soft asserts, пропуск схемных проверок.
* [ ] Мини-набор тестов: валидация схемы, сверка путей, поиск секретных паттернов.
* [ ] PASS: все проверки зелёные; FAIL: хотя бы один критический пункт.

## Таблица типовых ошибок

| Ошибка | Описание | Критичность |
|--------|----------|-------------|
| Невалидный манифест | `artifact_manifest` не проходит схему валидации | Высокая |
| Неправильные пути | Пути файлов выходят за пределы `tmp/{run_id}/` | Высокая |
| Секреты в коде | Наличие ключей, паролей, URL в файлах | Высокая |
| Отсутствие логов | Нет события `llm_call_end` в логах | Средняя |
| Несоответствие контракту | Созданные файлы не соответствуют `package_contract` | Высокая |
