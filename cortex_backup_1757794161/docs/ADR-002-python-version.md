# ADR-002: Выбор версии Python

## Статус
accepted

## Дата
2025-08-21

## Контекст
Проект использует Python 3.12, но для долгосрочной поддержки и стабильности рекомендуется использовать Python 3.11. Необходимо определить стратегию миграции.

## Решение
1. На MVP продолжаем использовать Python 3.12
2. Планируем миграцию на Python 3.11 через pyenv/docker при необходимости
3. Обновляем _capsule.md с указанием Python 3.11 как базовой версии, но допускаем 3.12 на MVP (фикс ADR)

## Альтернативы
- Оставить Python 3.12 как есть
- Немедленно перейти на Python 3.11

## Почему так
- Python 3.11 более стабилен и имеет лучшую поддержку со стороны сообщества
- Python 3.12 имеет новые функции, но может быть менее стабильным
- Постепенная миграция позволяет избежать рисков на MVP

## Последствия
- В _capsule.md указано Python 3.11 как базовая версия
- На MVP допускается использование Python 3.12
- Создан план миграции на Python 3.11

## Риски
- Зависимости могут быть несовместимы с Python 3.11
- Требуется дополнительное время на тестирование при миграции
