# API Documentation\n\n## Обзор\n\nЭтот документ описывает API Feature Factory.\n\n## Базовый URL\n\n- Тест: `https://etl-tst.chococraft.ru/api/v1`\n- Продакшен: `https://etl.chococraft.ru/api/v1`\n\n## Аутентификация\n\nAPI использует Basic Auth. Учетные данные передаются в заголовке `Authorization`.\n\n## Корреляция запросов\n\nВсе запросы должны содержать заголовок `X-Request-ID` для корреляции логов.\n\n## Обработка ошибок\n\nAPI возвращает стандартные HTTP коды ошибок:\n- 200: Успешный запрос\n- 400: Некорректный запрос\n- 401: Неавторизованный доступ\n- 404: Ресурс не найден\n- 429: Превышен лимит запросов\n- 500: Внутренняя ошибка сервера\n\nТело ответа при ошибке:\n```json\n{\n  \"error\": \"ERROR_CODE\",\n  \"detail\": \"Подробное описание ошибки\"\n}\n```\n\n## Эндпоинты\n\n### Health Checks\n\n#### GET /health\n\nПроверка общего состояния системы.\n\n**Response:**\n```json\n{\n  \"status\": \"ok\"\n}\n```\n\n#### GET /health/live\n\nLiveness probe.\n\n**Response:**\n```json\n{\n  \"status\": \"ok\"\n}\n```\n\n#### GET /health/ready\n\nReadiness probe.\n\n**Response:**\n```json\n{\n  \"status\": \"ok\"\n}\n```\n\n#### GET /health/deps\n\nПроверка зависимостей.\n\n**Response:**\n```json\n{\n  \"status\": \"ok\"\n}\n```\n\n### Orchestrator\n\n#### POST /orchestrator/features\n\nСоздание новой фичи.\n\n**Request:**\n```json\n{\n  \"title\": \"string\",\n  \"intent\": \"object or null\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"id\": \"integer\",\n  \"status\": \"NEW|PLANNED|RUNNING|DONE|FAILED\"\n}\n```\n\n**Ошибки:**\n- 400: Некорректный запрос\n- 409: Фича уже существует\n\n#### POST /orchestrator/features/{id}/plan\n\nГенерация плана для фичи.\n\n**Response (200):**\n```json\n{\n  \"feature_id\": \"integer\",\n  \"tasks\": [\n    {\n      \"id\": \"integer\",\n      \"role\": \"string\",\n      \"status\": \"NEW\"\n    }\n  ],\n  \"package_contract\": \"object\"\n}\n```\n\n**Ошибки:**\n- 400: Некорректный запрос\n- 404: Фича не найдена\n\n#### POST /orchestrator/features/{id}/run\n\nЗапуск выполнения фичи.\n\n**Response (200):**\n```json\n{\n  \"run_id\": \"string\",\n  \"state\": \"STARTED|RESUMED\"\n}\n```\n\n**Ошибки:**\n- 400: Некорректный запрос\n- 404: Фича не найдена\n\n#### GET /orchestrator/graph/{run_id}/status\n\nПолучение статуса запуска графа.\n\n**Response (200):**\n```json\n{\n  \"run_id\": \"string\",\n  \"graph\": \"G1\",\n  \"status\": \"RUNNING|DONE|FAILED\",\n  \"last_checkpoint\": \"string\"\n}\n```\n\n**Ошибки:**\n- 404: Запуск графа не найден\n\n### Maintainer\n\n#### POST /maintainer/intent\n\nГенерация интента из естественного языка.\n\n**Request:**\n```json\n{\n  \"nl_text\": \"string\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"nl_text\": \"string\",\n  \"intent_json\": \"object\",\n  \"issues\": [\"string\"],\n  \"suggestions\": [\"string\"]\n}\n```\n\n**Ошибки:**\n- 400: Некорректный запрос\n- 429: Превышен лимит токенов\n- 500: Внутренняя ошибка сервера\n\n#### POST /maintainer/plan\n\nГенерация плана из интента.\n\n**Request:**\n```json\n{\n  \"intent_json\": \"object\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"intent_json\": \"object\",\n  \"dag\": [\n    {\n      \"id\": \"uuid\",\n      \"name\": \"string\",\n      \"kind\": \"job|code|doc|test\",\n      \"role\": \"Architect|Dev|QA|Scribe\",\n      \"preconditions\": [\"string\"],\n      \"postconditions\": [\"string\"],\n      \"idempotency_key\": \"string\",\n      \"retry\": {\n        \"max\": 2,\n        \"backoff\": \"exp:5,30,120\"\n      },\n      \"deadline\": \"PT10M\",\n      \"models\": [\"flash\", \"qwen-fallback\"],\n      \"outputs\": [\"files|logs|tables\"],\n      \"dod\": [\"string\"],\n      \"severity\": \"low|med|high\"\n    }\n  ],\n  \"package_contract\": \"object\"\n}\n```\n\n**Ошибки:**\n- 400: Некорректный запрос\n- 429: Превышен лимит токенов\n- 500: Внутренняя ошибка сервера\n\n### Stream\n\n#### GET /stream/events\n\nПолучение потока событий в реальном времени через Server-Sent Events.\n\n**Events:**\n- `job_started`\n- `job_finished`\n- `error`\n- `index_updated`\n- `doc_updated`\n- `llm_call_end`\n\n### Logs\n\n#### GET /logs/tail\n\nПолучение последних записей логов.\n\n**Query Parameters:**\n- `limit`: количество записей (по умолчанию 100)\n- `component`: фильтр по компоненту\n- `level`: фильтр по уровню лога\n- `event`: фильтр по событию\n- `agent_role`: фильтр по роли агента\n\n**Response (200):**\n```json\n[\n  {\n    \"ts\": \"datetime\",\n    \"level\": \"string\",\n    \"env\": \"string\",\n    \"component\": \"string\",\n    \"agent_role\": \"string\",\n    \"run_id\": \"string\",\n    \"task_id\": \"string\",\n    \"correlation_id\": \"string\",\n    \"event\": \"string\",\n    \"kv\": \"object\"\n  }\n]\n```\n\n### Tokens\n\n#### GET /admin/tokens\n\nПолучение статистики расхода токенов.\n\n**Response (200):**\n```json\n[\n  {\n    \"role\": \"string\",\n    \"model\": \"string\",\n    \"input_tokens\": \"integer\",\n    \"output_tokens\": \"integer\",\n    \"total_tokens\": \"integer\",\n    \"cost\": \"number\"\n  }\n]\n```\n\n### Index\n\n#### GET /index/symbol\n\nПолучение информации о символе.\n\n**Query Parameters:**\n- `name`: имя символа\n\n#### GET /index/calls\n\nПолучение информации о вызовах функции.\n\n**Query Parameters:**\n- `name`: имя функции\n\n## Rate Limiting\n\nAPI может применять ограничения на количество запросов. При превышении лимита возвращается код 429.\n\n## CORS\n\nAPI настроен на работу с доменами etl-tst.chococraft.ru и etl.chococraft.ru.\n\n## WebSocket соединения\n\nДля реал-тайм обновлений используется Server-Sent Events (SSE) по адресу `/stream/events`.\n\n## Пагинация\n\nДля эндпоинтов, возвращающих списки данных, может применяться пагинация через query параметры.\n\n## Фильтрация и сортировка\n\nНекоторые эндпоинты поддерживают фильтрацию и сортировку через query параметры.\n\n## Мониторинг\n\n### Метрики\n\nAPI предоставляет метрики для мониторинга:\n- Время отклика\n- Количество запросов\n- Количество ошибок\n- Использование ресурсов\n\n## Логирование\n\nВсе запросы к API логируются с использованием стандартного формата логов Feature Factory.\n\n## Безопасность\n\n### Шифрование\n\nВсе соединения с API должны использовать HTTPS.\n\n### Валидация данных\n\nВсе входные данные валидируются на стороне сервера.\n\n### Санитизация\n\nВсе выходные данные санитизируются для предотвращения XSS атак.\n\n## Производительность\n\n### Оптимизация запросов\n\nAPI оптимизирован для минимизации количества запросов и объема передаваемых данных.\n\n### Кэширование\n\nНекоторые эндпоинты поддерживают кэширование. Заголовок `Cache-Control` указывает на политику кэширования.\n\n## Примеры использования\n\n### Создание фичи\n\n```bash\ncurl -X POST https://etl-tst.chococraft.ru/api/v1/orchestrator/features \\\n  -H \"Authorization: Basic $(echo -n 'username:password' | base64)\" \\\n  -H \"X-Request-ID: $(uuidgen)\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"title\": \"New Feature\", \"intent\": {\"action\": \"create\"}}'\n```\n\n### Генерация интента\n\n```bash\ncurl -X POST https://etl-tst.chococraft.ru/api/v1/maintainer/intent \\\n  -H \"Authorization: Basic $(echo -n 'username:password' | base64)\" \\\n  -H \"X-Request-ID: $(uuidgen)\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"nl_text\": \"Create a new feature to import data from CSV\"}'\n```\n\n### Подписка на поток событий\n\n```javascript\nconst eventSource = new EventSource('https://etl-tst.chococraft.ru/api/v1/stream/events', {\n  withCredentials: true\n});\n\neventSource.addEventListener('job_started', function(event) {\n  console.log('Job started:', event.data);\n});\n\neventSource.addEventListener('job_finished', function(event) {\n  console.log('Job finished:', event.data);\n});\n```\n\n##
