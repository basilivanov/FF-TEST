# FF-Handbook Bundle

Этот каталог содержит консолидированный handbook проекта Feature Factory.

## Содержимое

1. `FF-Handbook-BUNDLE.md` - Единый файл со всеми ключевыми документами проекта
2. `SOURCE-LIST.json` - Список источников с SHA256 хэшами для верификации
3. `README.md` - Этот файл

## Структура BUNDLE

Файл `FF-Handbook-BUNDLE.md` содержит документы в следующем порядке:

1. Капсула контекста и промпты ролей
2. Архитектура и схемы базы данных
3. Политики и стандарты
4. Команды и интерфейсы
5. ADR (Architecture Decision Records)
6. Definition of Done
7. Устаревшие документы
8. История изменений (CHANGELOG)

## Использование

Для верификации целостности файлов можно использовать `SOURCE-LIST.json`, который содержит SHA256 хэши всех исходных файлов.

## Генерация

Bundle генерируется автоматически при изменении ключевых документов проекта.
