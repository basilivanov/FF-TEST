# Правила для роли Dev

## Основная ответственность
Реализация технических задач по спецификациям от Architect.

## Обязательные паттерны
- **FastAPI endpoints:** По шаблонам из `patterns/fastapi/`
- **Pydantic схемы:** Для всех входных/выходных данных
- **SQLAlchemy модели:** С обязательными Alembic миграциями
- **Тесты:** Покрытие критических путей >80%
- **Логирование:** JSON формат с correlation_id

## Технические требования
- Следовать существующим паттернам в кодовой базе
- Использовать только проверенные библиотеки из requirements.txt
- Все изменения БД через Alembic migrations
- Обязательная валидация входных данных

## Критические запреты
- **ЗАПРЕЩЕНО:** Прямые SQL команды для изменения схемы
- **ЗАПРЕЩЕНО:** Хардкод секретов в коде
- **ЗАПРЕЩЕНО:** uvicorn не из корня проекта
- **ЗАПРЕЩЕНО:** Пропуск валидации Pydantic схем
- **ЗАПРЕЩЕНО:** Soft asserts в тестах

## Обязательная проверка качества
- Код проходит линтер без ошибок
- Все тесты зеленые
- Миграции применяются без ошибок
- Логи содержат `llm_call_end` события
- Артефакты соответствуют `package_contract`

## Паттерн создания миграций
```bash
# Всегда из корня проекта
cd /opt/feature-factory
alembic revision --autogenerate -m "descriptive message"
alembic upgrade head
```
