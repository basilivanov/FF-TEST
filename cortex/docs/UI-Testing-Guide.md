## Типы тестов

### Unit Тесты

Unit тесты проверяют отдельные компоненты и функции в изоляции.

**Цель покрытия**: 70% для всех компонентов

**Инструменты**:
- Jest
- React Testing Library

**Примеры**:
- Тестирование отдельных UI компонентов (StatusPill, CodeBlock)
- Тестирование хуков и утилит
- Тестирование функций обработки данных

### Integration Тесты

Integration тесты проверяют взаимодействие между компонентами и с API.

**Цель покрытия**: 60% для API интеграций

**Инструменты**:
- Jest
- React Testing Library
- MSW (для мокирования API)

**Примеры**:
- Тестирование страниц с мокированными данными
- Тестирование форм с валидацией
- Тестирование таблиц с фильтрацией/сортировкой

### E2E Тесты

E2E тесты проверяют полные пользовательские сценарии в реальном браузере.

**Цель покрытия**: 50% для критических пользовательских сценариев

**Инструменты**:
- Playwright

**Примеры**:
- Авторизация и навигация
- Создание и управление фичами
- Работа с чатом и генерация интентов
- Просмотр логов и мониторинг состояния

### Performance Тесты

Performance тесты проверяют скорость загрузки и отклика интерфейса.

**Цель покрытия**: 40% для критических путей

**Инструменты**:
- Playwright
- Lighthouse (в будущем)

**Примеры**:
- Время загрузки страниц
- Время отклика на действия пользователя
- Оптимизация рендеринга больших списков
- Кэширование данных

### Security Тесты

Security тесты проверяют уязвимости и защиту интерфейса.

**Цель покрытия**: 30% для критических точек входа

**Инструменты**:
- Playwright
- OWASP ZAP (в будущем)

**Примеры**:
- Проверка авторизации и аутентификации
- Проверка защиты от XSS и CSRF
- Проверка заголовков безопасности
- Проверка обработки чувствительных данных

### Accessibility Тесты

Accessibility тесты проверяют доступность интерфейса для пользователей с ограниченными возможностями.

**Цель покрытия**: 20% для основных компонентов

**Инструменты**:
- Playwright
- Axe-core (в будущем)

**Примеры**:
- Проверка контрастности цветов
- Проверка навигации с клавиатуры
- Проверка ARIA атрибутов
- Проверка альтернативного текста для изображений

### Compatibility Тесты

Compatibility тесты проверяют работу интерфейса в различных браузерах и устройствах.

**Цель покрытия**: 10% для различных браузеров/устройств

**Инструменты**:
- Playwright

**Примеры**:
- Поддержка различных браузеров (Chrome, Firefox, Safari, Edge)
- Адаптивность для разных размеров экранов
- Поддержка сенсорных устройств
- Работа с различными настройками браузера
