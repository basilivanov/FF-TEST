# Руководство по операциям (Ops Guide)

Этот документ описывает инструменты и процедуры, используемые для операционного управления системой Feature Factory.

## Sudo-обертки

Система Feature Factory использует набор `sudo`-оберток для безопасного выполнения административных задач. Эти обертки предоставляют стандартизированный и контролируемый способ взаимодействия с системными службами.

### ff-orch-stop-safe
**Назначение:** Безопасно останавливает службу `feature-factory-test.service`.
**Когда использовать:** Используйте эту обертку, когда необходимо остановить работу основного сервиса Feature Factory, например, для проведения обслуживания или обновления. Она обеспечивает корректное завершение всех процессов.

### ff-orch-start-safe
**Назначение:** Безопасно запускает службу `feature-factory-test.service`.
**Когда использовать:** Используйте эту обертку для запуска основного сервиса Feature Factory после его остановки или при первом развертывании. Она гарантирует, что все необходимые зависимости запущены.

### ff-orch-status-safe
**Назначение:** Проверяет статус службы `feature-factory-test.service`.
**Когда использовать:** Используйте эту обертку для быстрого получения информации о текущем состоянии службы Feature Factory (работает ли, остановлена, есть ли ошибки). Полезно для мониторинга и быстрой диагностики.

### ff-logs-read
**Назначение:** Читает последние N строк логов службы `feature-factory-test.service`.
**Когда использовать:** Используйте эту обертку для просмотра последних записей в логах сервиса. Это критически важно для отладки, выявления проблем и мониторинга активности системы.

### ff-netdiag-8081
**Назначение:** Запускает сетевую диагностику для порта 8081.
**Когда использовать:** Используйте эту обертку для диагностики проблем с сетевым доступом к порту 8081, на котором работает сервис Feature Factory. Полезно при проблемах с подключением или недоступностью сервиса.


## Перезапуск и статус сервисов

- Рестарт через унифицированные скрипты репозитория:
  - `bin/ff-restart` — перезапускает TEST и PROD по умолчанию
  - `bin/ff-restart --test` — только TEST
  - `bin/ff-restart --prod` — только PROD
  - `bin/ff-status` — сводный статус (через обертки/`systemctl`)

Скрипты предпочитают штатные обертки `/opt/feature-factory/bin/ff-orch-*-safe`, если они доступны, и автоматически fallback‑ят к `systemctl`.

## Обновление CLI провайдеров (Codex/Claude/Gemini/Qwen)

- Выполнить `sudo bin/ff-cli-update --restart-services`
- Скрипт:
  - Обновит npm‑пакеты в NVM‑окружении пользователя `feature`
  - Перелинкует `/usr/local/bin/{codex,claude,gemini,qwen}` на свежие бинарники
  - Перезапустит сервисы через обертки/`systemctl` (см. выше)
