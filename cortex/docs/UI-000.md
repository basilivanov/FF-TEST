# Dashboard KPI

## Карточки

* **Now**: активные задачи, run_id, роли.
* **Queue**: фичи NEW/PLANNED, ожидание.
* **Errors**: последние REJECT/FAIL, коды и причины.
* **Budget**: usage/день по ролям (график).
* **Throughput**: фичи/день, таски/час.
* **Latency**: p95 API/LLM.

## Источники данных

* `/api/v1/orchestrator/*`, `/admin/tokens`, `/api/v1/logs`, `/api/v1/stream/events`.

## Частоты обновления

* Now/Errors: 3–5s; Budget: 30–60s; прочее: 10–15s.

## SLO (пример)

* p95 API < 250ms; E2E pass-rate ≥ 95%; fallback < 10%; REJECT < 5%/нед.
