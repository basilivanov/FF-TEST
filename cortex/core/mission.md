# FeatureFactory Mission

FeatureFactory — автоматизированное производство бизнес-фич без участия человека.

## Цель системы

Управляемые гейты, полная трассировка, строгие API-контракты для создания внутренних фич силами агентов.

## Принципы работы

- Люди задают цели и принимают релизы
- Агенты выполняют всю техническую работу
- Каждое изменение отслеживается через correlation_id
- Нет компромиссов в качестве ради скорости
