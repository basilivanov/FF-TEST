# Core Principles

## Фундаментальные принципы FeatureFactory

- **context_first** — контекст важнее скорости выполнения
- **corr_id_required** — каждая операция имеет correlation_id для трассировки
- **no_mocks_in_prod** — продакшн работает только с реальными интеграциями
- **alembic_only_for_schema** — изменения схемы БД только через Alembic миграции
- **docsync_gated** — документация синхронизирована с кодом через CI гейты

## Дополнительные принципы

- **atomic_operations** — операции выполняются полностью или откатываются
- **immutable_artifacts** — артефакты не изменяются после создания
- **single_source_of_truth** — один источник правды для каждого типа данных
