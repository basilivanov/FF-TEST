# Миграции базы данных

В этом проекте используется Alembic для управления миграциями базы данных.

## Основные команды

### Применение миграций
```bash
alembic upgrade head
```

### Создание новой миграции
```bash
alembic revision -m "описание миграции"
```

### Откат миграций
```bash
alembic downgrade -1  # Откат последней миграции
alembic downgrade base  # Откат всех миграций
```

## Структура каталогов

- `versions/` - каталог с файлами миграций
- `env.py` - конфигурация Alembic
- `script.py.mako` - шаблон для генерации новых миграций

## Переменные окружения

Для работы с миграциями необходимо установить переменную окружения `DATABASE_URL`, которая указывает на базу данных проекта.

Пример:
```bash
export DATABASE_URL=sqlite:///./test.db
```
