# QA-отчет: аудит путей БД и запрещённых дефолтов (E9-DB-AUDIT-QA)

## Цель
Проверить, что в коде не используются запрещенные пути к БД и что конфигурация соответствует новым стандартам.

## Выполненные проверки

### 1. Проверка на запрещенные строки

**Критерий**: Fail, если найдены строки вида `sqlite:///./` или `:memory:`.

**Результат**: Проверка выполнена успешно. В коде не найдено запрещенных строк.

**Детали**:
- Проверены все `.py` файлы в директории `/opt/feature-factory/app`.
- Найдены и исправлены все хардкоды путей к БД в предыдущих задачах.
- Запрещено использование in-memory баз данных в продакшене и тестировании.

### 2. Проверка разделения URL для app и index

**Критерий**: Проверка, что app и index читают разные URL по ключам ENV.

**Результат**: Проверка выполнена успешно. App и index используют разные URL.

**Детали**:
- `app` использует `DATABASE_URL` из переменной окружения.
- `index` использует `INDEX_DATABASE_URL` из переменной окружения.
- Оба URL являются абсолютными путями.

### 3. Smoke-тесты API

**Критерий**: Smoke `/api/v1/orchestrator/*` возвращают 200/4xx без 500.

**Результат**: Smoke-тесты выполнены успешно. Все эндпоинты возвращают корректные коды ответов.

**Детали**:
- `POST /api/v1/orchestrator/features` - 200 (успешно)
- `POST /api/v1/orchestrator/features/{id}/plan` - 200 (успешно)
- `POST /api/v1/orchestrator/features/{id}/run` - 200 (успешно)
- `GET /api/v1/orchestrator/graph/{run_id}/status` - 200 (успешно)
- `GET /api/v1/orchestrator/tasks` - 200 (успешно)
- `GET /api/v1/orchestrator/runs` - 200 (успешно)

## Заключение

Все проверки пройдены успешно. Код соответствует новым стандартам конфигурации БД:
- Используются только абсолютные пути к файлам БД.
- Запрещено использование in-memory баз данных.
- App и index используют разные URL.
- Все API эндпоинты работают корректно без 500 ошибок.
