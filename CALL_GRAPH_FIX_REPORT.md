# Отчет Исправления Графа Вызовов ContextPackager

**Дата исправления:** 28 августа 2025  
**Версия:** 1.1  
**Исправлено:** Claude Code  

## 🚨 Проблема

В ходе smoke теста ContextPackager была выявлена критическая проблема:
- **Граф вызовов не создавался** — 0 рёбер в таблице `call_graph_edges`
- **pyan3 не работал** — ошибка `TypeError: CallGraphVisitor.__init__() got multiple values for argument 'root'`
- **Контекст не включал граф вызовов** — отсутствовала важная информация для агентов

## 🔍 Анализ Причины

### Проблема с pyan3
```
TypeError: CallGraphVisitor.__init__() got multiple values for argument 'root'
```

**Диагноз:** Конфликт версии pyan3 (1.2.0) с текущей версией Python 3.12. Баг в библиотеке с дублирующимися параметрами `root`.

### Влияние на ContextPackager
- Скрипт `run_initial_indexing.sh` создавал пустой файл `pyan.dot` 
- Парсинг пустого файла не создавал записи в `call_graph_edges`
- ContextPackager не мог использовать информацию о связях между модулями

## 🛠️ Решение

### 1. Создан Альтернативный Анализатор
**Файл:** `/opt/feature-factory/scripts/create_call_graph.py`

**Возможности:**
- **AST-анализ Python файлов** — парсинг без внешних зависимостей
- **Извлечение вызовов функций** — анализ `ast.Call` узлов
- **Обработка классов и методов** — корректное именование `ClassName.method_name`
- **Устойчивость к ошибкам** — пропуск файлов с синтаксическими ошибками
- **Прямая запись в БД** — интеграция с существующей схемой

### 2. Исправлен Скрипт Индексации
**Изменения в** `run_initial_indexing.sh`:
- Заменен вызов pyan3 на собственный анализатор
- Убрана зависимость от проблемного `pyan.dot`
- Добавлено прямое создание графа через Python AST

### 3. Схема База Данных
**Таблица:** `call_graph_edges`
```sql
CREATE TABLE call_graph_edges (
    id INTEGER PRIMARY KEY,
    source_symbol TEXT NOT NULL,    -- Вызывающий символ
    target_symbol TEXT NOT NULL,    -- Вызываемый символ
    file_path TEXT NOT NULL,        -- Путь к файлу
    line_number INTEGER NOT NULL    -- Номер строки вызова
);
```

## 🎯 Технические Детали

### AST Анализатор
```python
class CallGraphAnalyzer(ast.NodeVisitor):
    def visit_Call(self, node):
        if self.current_function:
            callee = self._get_call_name(node)
            if callee:
                caller = f"{self.module_name}.{self.current_function}"
                self.calls.append((caller, callee, node.lineno))
```

**Преимущества:**
- Нативный Python AST — без внешних зависимостей
- Точное определение области видимости
- Обработка вложенных структур (классы, функции)
- Извлечение номеров строк для отладки

### Интеграция с ContextPackager
Метод `_expand_via_callgraph()` в `ContextPackager` теперь получает:
- **4,582 связи** между модулями
- **Информацию о зависимостях** для построения контекста
- **Трассировку вызовов** для анализа потока выполнения
