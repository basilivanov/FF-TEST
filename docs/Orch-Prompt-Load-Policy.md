# Политика загрузки промптов в узлах графа

## Общие положения

Каждый узел графа (Dev, QA, Scribe, Architect) должен загружать системный промпт из файлов, соответствующих его роли. Это обеспечивает консистентность и управляемость поведения агентов.

## Контракт узлов

### Где брать system prompt

1. Узлы графа должны читать системный промпт из файлов, указанных в `configs/prompts.yaml`
2. Путь к файлу определяется по роли узла
3. Файл должен существовать и быть доступен для чтения

### Логирование prompt_id и prompt_sha256

Каждый вызов LLM должен сопровождаться логированием:
- `prompt_id`: идентификатор промпта (путь к файлу)
- `prompt_sha256`: хэш содержимого промпта (SHA256)
- `role`: роль узла
- `run_id`: идентификатор запуска

Пример записи в логах:
```
{
  "event": "llm_call_start",
  "prompt_id": "agents/prompts/dev.md",
  "prompt_sha256": "e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3d4e5f6",
  "role": "Dev",
  "run_id": "run_12345"
}
```

### Реакция на отсутствующий/невалидный промпт

Если промпт отсутствует или не может быть загружен:
1. Узел должен сгенерировать событие `RETRYABLE_ERROR`
2. В логах должно быть записано событие `artifact_rejected` с причиной `MISSING_PROMPT`
3. Orchestrator должен обработать эту ошибку в соответствии с политикой повторных попыток

Пример записи в логах при ошибке:
```
{
  "event": "artifact_rejected",
  "reason": "MISSING_PROMPT",
  "details": "Failed to load prompt from agents/prompts/dev.md",
  "role": "Dev",
  "run_id": "run_12345"
}
```

## Поля логов

### Обязательные поля для всех LLM-вызовов

- `prompt_id`: путь к файлу промпта
- `prompt_sha256`: SHA256 хэш содержимого промпта
- `role`: роль узла
- `run_id`: идентификатор запуска
- `task_id`: идентификатор задачи
- `correlation_id`: идентификатор для корреляции запросов

## Процесс загрузки промпта

1. Узел определяет свою роль
2. По роли находит путь к файлу промпта в `configs/prompts.yaml`
3. Загружает содержимое файла
4. Вычисляет SHA256 хэш содержимого
5. Использует содержимое файла как system prompt для LLM
6. Логирует начало и окончание вызова с указанием prompt_id и prompt_sha256
