# QA-Checklist: Architect

## Общие проверки

* [ ] Проверяем: валидность `package_contract.yaml` и `plan.dsl.yaml`, наличие всех обязательных полей.
* [ ] Запрещено: отсутствие контракта или плана, невалидные ссылки на артефакты/таблицы.
* [ ] Мини-набор тестов: валидация схем контракта и плана, проверка ролей в DAG.
* [ ] PASS: все проверки зелёные; FAIL: хотя бы один критический пункт.

## Таблица типовых ошибок

| Ошибка | Описание | Критичность |
|--------|----------|-------------|
| Нет контракта | Отсутствует `package_contract.yaml` | Высокая |
| Нет плана | Отсутствует `plan.dsl.yaml` | Высокая |
| Невалидный контракт | `package_contract` не проходит схему валидации | Высокая |
| Невалидный план | `plan.dsl` не проходит схему валидации | Высокая |
| Нет ролей | В DAG отсутствуют обязательные роли (Dev, QA, Scribe) | Высокая |
| Битые ссылки | Ссылки на несуществующие артефакты/таблицы | Высокая |
