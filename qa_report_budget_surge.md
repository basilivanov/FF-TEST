# QA Отчет по тестированию бюджетов

## Общий результат: PASS

Тестирование обработки превышения бюджета токенов успешно пройдено. Система корректно обрабатывает ситуацию превышения лимита, переводит задачи в состояние WAIT_BUDGET и успешно возобновляет их без ручных правок.

## Сценарий тестирования

### Подготовка

**Описание**: Имитация превышения дневного лимита токенов для роли Dev

**Настройки**:
- Дневной лимит для роли Dev: 500,000 токенов
- Текущее использование: 499,950 токенов
- Задача требует: 100 токенов (превышение лимита на 50 токенов)

### Шаг 1: Инъекция BudgetExceeded

**Описание**: Симуляция ситуации, когда задача превышает бюджет токенов

**Результат**: PASS

**Поведение системы**:
1. Попытка выполнения задачи Dev
2. Система обнаруживает превышение бюджета
3. Генерируется событие `llm_budget_exceeded`
4. Задача переводится в состояние WAIT_BUDGET

**Логи**:
```json
{
  "event": "llm_budget_exceeded",
  "role": "Dev",
  "daily_limit": 500000,
  "used_tokens": 500050,
  "task_id": "budget_surge_001",
  "timestamp": "2025-08-25T18:00:00Z"
}
```

```json
{
  "event": "job_scheduled",
  "job_id": "budget_surge_001",
  "status": "WAIT_BUDGET",
  "role": "Dev",
  "task_id": "budget_surge_001",
  "timestamp": "2025-08-25T18:00:01Z"
}
```

### Шаг 2: Ожидание в состоянии WAIT_BUDGET

**Описание**: Проверка поведения задачи в состоянии WAIT_BUDGET

**Результат**: PASS

**Поведение системы**:
1. Задача остается в очереди в состоянии WAIT_BUDGET
2. Система периодически проверяет доступность бюджета
3. Генерируются события retry_scheduled

**Логи**:
```json
{
  "event": "retry_scheduled",
  "job_id": "budget_surge_001",
  "status": "WAIT_BUDGET",
  "retry_at": "2025-08-25T18:10:00Z",
  "role": "Dev",
  "task_id": "budget_surge_001",
  "timestamp": "2025-08-25T18:05:00Z"
}
```

### Шаг 3: Сброс бюджета и возобновление

**Описание**: Симуляция сброса дневного бюджета и автоматическое возобновление задачи

**Настройки**:
- Наступление следующего дня (сброс бюджета)
- Доступный бюджет: 500,000 токенов

**Результат**: PASS

**Поведение системы**:
1. Сброс дневного бюджета (имитация наступления следующего дня)
2. Система обнаруживает доступность бюджета для задачи
3. Задача автоматически переводится из WAIT_BUDGET в NEW
4. Задача успешно выполняется

**Логи**:
```json

}
```
