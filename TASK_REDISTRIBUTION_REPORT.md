# Перераспределение задач из-за упавшего агента (квоты)

## Ситуация
- В системе обнаружена задача в состоянии WAIT_BUDGET (ID: 19)
- Задача не может быть выполнена из-за превышения бюджета токенов
- Требуется перераспределение задачи на другого исполнителя

## Действия
1. Создан дубликат задачи с provider_override (ID: 20)
2. Оригинальная задача остается в состоянии WAIT_BUDGET
3. Новая задача создана в состоянии NEW с указанием провайдера gemini

## Детали задач

### Оригинальная задача (ID: 19)
- Роль: Dev
- Статус: WAIT_BUDGET
- Конфигурация: стандартная маршрутизация (flash → qwen → gemini)

### Дубликат задачи (ID: 20)
- Роль: Dev
- Статус: NEW
- Конфигурация: с provider_override="gemini"

## Политика на MVP
- Авто-резюм при дропе не делаем — вручную перекидываем таску на другого исполнителя/провайдера
- В DSL таски выставлять provider_override:
  - gemini для Dev/QA/Scribe
  - claude/gpt для Architect/Maintainer (если квоты есть), иначе gemini
- Если таска в WAIT_BUDGET — оставить, луп её подхватит на следующем слоте
- Срочные задачи — создать дубль таски с override (и пометкой в комментарии), оригинал оставить ждать

## Следующие шаги
- Луп оркестратора подхватит новую задачу на следующей итерации
- После выполнения задачи статус будет обновлен
- Оригинальная задача в состоянии WAIT_BUDGET будет обработана на следующем слоте
