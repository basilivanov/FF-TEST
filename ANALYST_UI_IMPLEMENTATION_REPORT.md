## 🔧 Техническая реализация

### Архитектура решения
```
[UI Toggle] → [Zustand State] → [API Call] → [Backend Router] → [LLM Analyst]
     ↓              ↓               ↓               ↓              ↓
[ToggleGroup] → [analystType] → [POST /analyst] → [InternalAnalyst] → [Intent + Feature]
                                                  → [BusinessAnalyst] → [Intent + Feature]
```

### Формат API запроса
```json
{
  "text": "Описание задачи от пользователя",
  "type": "INTERNAL" // или "BUSINESS" 
}
```

### Формат ответа
```json
{
  "feature_id": 123,
  "status": "NEW", 
  "type": "INTERNAL",
  "title": "Название созданной фичи",
  "intent": { ... },
  "interpretation": "Интерпретация запроса аналитиком"
}
```
