# Спецификация UI для каталога ролей

## Общие положения

Этот документ описывает макет и DTO для каталога ролей в Admin UI, включая отображение уставов, промптов, хэшей и функцию Dry-Run.

## Требования к реализации

### Утверждённый макет
- ✅ Список ролей с колонками: Роль, Устав, Промпт, Хэш промпта
- ✅ Панель правой части с уставом/промптом/хэшем/кнопкой Dry-Run
- ✅ Возможность перехода к полному просмотру устава и промпта
- ✅ Модальное окно Dry-Run с возможностью ввода текста и просмотра результата

### Функциональность
- ✅ Отображение всех ролей в таблице
- ✅ Просмотр содержимого уставов и промптов
- ✅ Отображение хэшей промптов
- ✅ Функция Dry-Run для тестирования промптов
- ✅ Оценка количества токенов в промпте
