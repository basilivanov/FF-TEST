## 🎯 Архитектурные решения

### Режимы работы системы:
1. **Production**: `GRAPH_AVAILABLE=True` → реальный LangGraph ✅
2. **Test Mode**: `GRAPH_AVAILABLE=False` + `TEST_MODE=true` → mock_graph_execution  
3. **Broken State**: `GRAPH_AVAILABLE=False` + `TEST_MODE!=true` → ничего не выполняется ❌

### Выбрано: Production режим для E2E
- Настоящий планировщик задач
- Реальные узлы графа Dev→Gate→QA→Scribe→Apply
- Полная интеграция с LLM роутингом
- Чекпоинты для resilience
